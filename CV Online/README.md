# CV Online — Ali Mufty Ramdhani

Web aplikasi CV / Resume Online dengan React, Material UI, React Router, React Hooks, dan External API.

## Menjalankan project

```bash
npm install
npm run dev
```

Buka URL yang muncul di terminal (biasanya `http://localhost:5173`).

## Build untuk production / VPS

```bash
npm run build
```

Hasil ada di folder `dist/`. Upload isi `dist/` ke VPS/static hosting.

## Fitur

- React Hooks (`useState`, `useEffect`, custom hooks)
- External API (Quote + GitHub)
- React Router (multi halaman)
- Material UI (tema gelap–emas)
- Halaman Demo Video (YouTube / Google Drive)
