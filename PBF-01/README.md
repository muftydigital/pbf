# Praktikum PBF - Pertemuan 1

**Nama:** Ali Mufty Ramdhani

Repository/folder ini berisi hasil praktik kembali materi Pemrograman Berbasis Framework pada pertemuan pertama.

Materi yang dipelajari:

- Variable
- Array
- Arrow Function
- Class
- Destructuring
- Template Literal

Komentar pada kode ditambahkan berdasarkan pemahaman saya terhadap fungsi dari bagian-bagian kode yang dipraktikkan.

## Cara menjalankan

Buka `index.html` di browser, kemudian pilih materi yang ingin dicoba.
Untuk bagian yang menggunakan `console.log`, hasilnya dapat dilihat melalui Developer Tools pada browser.
