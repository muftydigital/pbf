# Praktikum PBF Pertemuan 12

Project ini merupakan praktik ulang materi pertemuan 12 menggunakan **Next.js, React Hook Form, API Route, Prisma, dan SQLite**.

Yang dipraktikkan di dalam project:
- membaca daftar kontak,
- menambah kontak,
- mengedit kontak,
- menghapus kontak,
- validasi input dengan React Hook Form,
- komunikasi halaman dengan API Route,
- akses database menggunakan Prisma.

Kode JavaScript, JSX, Prisma, konfigurasi JavaScript, dan CSS sudah diberi komentar dengan bahasa sederhana sesuai pemahaman praktikum. File JSON tidak diberi komentar langsung karena JSON standar tidak mendukung komentar dan akan error jika dipaksakan.

## Menjalankan project

```bash
npm install
npm run dev
```

Aplikasi berjalan pada port **5000**.
